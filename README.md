# Putrajaya of Roblox

The official website for **Putrajaya of Roblox**, a Roblox Ro-State roleplay community.

## Included

- Responsive landing page inspired by modern editorial websites
- Community introduction and roleplay values
- Blog/news cards with placeholder posts
- Wiki hub with starter categories
- Join section linking to the current Google Site
- Mobile navigation and smooth scrolling
- No build tools required — this is a lightweight static site

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages

This repository is ready for GitHub Pages. In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub will publish the site at:

`https://putrajayarblx.github.io/putrajaya-of-roblox/`

## Customization

Replace the placeholder blog posts, Wiki links, community invite link, and gradient artwork in `index.html` and `styles.css` as official content becomes available.
